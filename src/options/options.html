反GEO · 设置

检测 AI 答案里的 GEO 投毒：站群互引、模板农场、隐藏指令注入、无一手来源。全部本地运行。

它怎么判断？ 三条硬证据：① 页面里藏了给 AI 看的指令（白字 / noscript / 注释）；② 同一答案的多条引用正文几乎同模板（≥3 个站点，站群批量生成）；③ 域名命中可疑名单。其余是弱信号叠加，不单独定罪。

检测行为

影响出现频率和速度。默认值适合大多数人。

启用检测关闭后所有页面不再注入界面
显示级别低于此级别的问题不打扰你
深度核查抓取被引用页面，检测隐藏指令与模板相似度。关闭后只看域名，很快但漏得多
每次最多抓取页数越多越准，越慢
最少引用数答案引用少于该数量时不检测

社区名单订阅 群体免疫

订阅一份公开的域名名单，别人标出来的内容农场你能直接命中。整个链路只发一个 GET，不上报任何数据。 地址可以是你的 Gist、GitHub Pages、对象存储，或本地 node scripts/blocklist-server.mjs。

外部数据源 进阶

插件从 DOM 只能看到"平台愿意展示的引用"。用本地代理（mitmproxy）能拿到响应里的 rag snippet —— 模型实际读进去的那段文本，判投毒更硬。不配也能正常用。

启动：pip install mitmproxy → mitmdump -s tools/antigeo_addon.py -p 8080 → 系统代理指向 127.0.0.1:8080 → 装 mitmproxy 根证书。

启用外部数据源拿不到就自动回退到 DOM，不会卡住检测

站点适配 DOM 改版自救

AI 平台改版换了 class 名，插件就会静默失效。不用等更新 —— 在目标页面点一下"探测"，插件会列出候选的答案容器，你选对的那个，它以后就记住了。
